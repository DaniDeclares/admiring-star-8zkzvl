# 5. CROSS-DIVISION RULE

A provider does not determine division ownership.

- Chris fixing a computer does not make Chris the division owner; classify the computer capability correctly and route Chris through fulfillment.
- Chris's property media belongs in the appropriate media/marketing structure, primarily Division 07.
- Chris's DTF/heat-press production belongs in Division 11.
- DANI planning an event belongs in Division 10 even if DANI also handles marketing, administration, logistics, notary, or coordination.
- A cleaning capability supporting a property turn remains structurally classified where it belongs and is mapped to Division 02 through cross-division application/dependency rather than duplicate SKUs.
- A notary capability supporting a real-estate closing remains Division 05 while Division 03 may own the broader commercial relationship.

**Fulfillment provider ≠ division owner.**
