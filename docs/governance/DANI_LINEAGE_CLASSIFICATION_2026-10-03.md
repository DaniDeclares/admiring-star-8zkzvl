# DANI Lineage Classification

Use these classifications when recovering prior engineering work:

- CURRENT AUTHORITY: current canonical source or runtime mechanism.
- STILL VALID / REUSE: older bounded behavior remains correct and should be carried forward.
- SUPERSEDED: newer authoritative machinery replaces the older approach.
- FAILED / ABANDONED: retain as evidence, not implementation authority.
- DRIFTED: still-relevant work must be reconstructed or reconciled against current main/runtime.
- GENUINELY MISSING: current source/runtime and history show the required capability does not exist, so bounded new work is justified.

Classify from current source, runtime state, migrations, tests, and release evidence rather than stale descriptions alone.
