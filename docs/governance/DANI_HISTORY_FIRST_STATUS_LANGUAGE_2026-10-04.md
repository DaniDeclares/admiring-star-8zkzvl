# Status Language

Use precise release language:
- Production-green: current live behavior verified.
- Tester-proven: non-production proof passed only.
- Ready for governed promotion: release gates satisfied but Production not yet verified.
- Legitimately held: exact dependency prevents safe progression.
- Drifted: prior work must be reconstructed/reconciled.
- Superseded/reconciled: newer authority replaces older candidate.

Do not collapse these states into done.
