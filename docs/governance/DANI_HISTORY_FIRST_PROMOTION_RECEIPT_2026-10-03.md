# DANI History-First Promotion Receipt

For any governed promotion, record:
- source branch and exact head;
- current-main SHA used for reconciliation;
- prior lineage reviewed and classifications;
- exact files/migrations/runtime objects being promoted;
- exact-head CI and proof receipts;
- security/rollback result;
- environment-specific dependencies;
- promotion/deployment receipt;
- exact Production verification;
- terminal state and any remaining hold.

This receipt prevents Tester proof, historical PR descriptions, or configuration state from being mistaken for current Production execution.
