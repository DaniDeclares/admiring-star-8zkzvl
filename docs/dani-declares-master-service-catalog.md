# Dani Declares LLC — Master Service Catalog

## Purpose

This document functions as the master operating service catalog for Dani Declares LLC. It is designed to support:

- client-facing proposals
- website service pages
- sales and outreach materials
- vendor and partner onboarding
- internal training and operations planning
- future division expansion

This catalog is intentionally broad and structured like a professional service directory used by facilities, operations, and business support firms.

## 12. Suggested Proposal Format

Each service can be packaged with the following fields:

- Service Code
- Service Name
- Division
- Client Type
- Description
- Deliverables
- Typical Time Frame
- Common Add-Ons
- Suggested Pricing Model
- SOP Reference

Example:

- PO-101 — Standard Apartment Turnover Reset
  - Client Type: Multifamily property managers
  - Deliverables: Unit reset, photo checklist, completion summary
  - Typical Time: 4–8 hours
  - Add-Ons: Carpet cleaning, lock change, welcome basket
  - Pricing Model: Flat fee or square footage-based quote
